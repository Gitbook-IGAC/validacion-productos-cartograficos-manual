# ¿Cómo valido mis productos cartográficos?

<figure><img src="../.gitbook/assets/ext_016_1.png" alt=""><figcaption></figcaption></figure>

Para asegurar la calidad y precisión de los productos cartográficos que se oficializan en la plataforma, el profesional de validación utiliza insumos base clave para cada tipo de producto (Base Vectorial, MDT u Ortoimagen).

Este proceso se lleva a cabo principalmente usando la herramienta ArcGIS Pro, que permite la inspección detallada y la aplicación de los criterios de calidad.

Los insumos que son esenciales para la verificación por parte del profesional validador son:

* El Producto Geográfico Final (Base Vectorial, MDT u Ortoimagen).
* El Límite del Proyecto (para verificar la cobertura o totalidad).
* La Imagen de Referencia (Ortoimagen) (crucial para Bases Vectoriales y MDT).
* Puntos de Comprobación y Control (para verificar la exactitud posicional).
* Toponimia (para validar la exactitud temática de los nombres geográficos).

A continuación, conocerá en detalle los criterios de calidad y los umbrales de error que el profesional aplica y como se validan para cada producto.

### Fase 1:

Estos son verificaciones generales que su producto debe cumplir sin excepción. Cualquier incumplimiento aquí suele resultar en un concepto "No Conforme" inmediato.

| Elemento Clave        | Lo que se Verifica                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Metadato              | Se verifica que esté completo, vigente, que corresponda al producto evaluado y cumpla con los estándares de descripción obligatorios de su producto.                      |
| Sistema de Referencia | Se verifica que el sistema de coordenadas sea el estándar oficial y obligatorio: MAGNA-SIRGAS 2018 Origen-Nacional. Para MDT, se verifica además el GEOCOL 2004 vertical. |
| Consistencia Temporal | Se verifica que la información tenga una antigüedad no mayor a 3 años (zonas urbanas/dinámicas) o 5 años (zonas rurales/estables).                                        |
| Formato de Entrega    | Que el archivo sea compatible y esté en el formato requerido para su tipo de producto (ej: GDB, GeoTIFF, etc.).                                                           |

## Fase 2: Criterios de Calidad Específicos

Una vez superada la Fase 1, se evalúa la calidad técnica y geométrica de los datos, donde existen umbrales de error que no deben superarse.

### Fase 3: Resultado Final de la validación

Al finalizar la revisión, el profesional registra de manera independiente todas las inconsistencias identificadas durante la validación técnica de cada producto en una geodatabase de inconsistencias. Esta geodatabase contiene los ítems de calidad evaluados y descritos previamente, lo que facilita su correcta clasificación. Finalmente, la información se cuantifica mediante una herramienta de totalización que permite obtener el porcentaje de error y, con ello, determinar el concepto final del producto.

> _**Validación Conforme (Aprobado):**_ El producto es apto para publicación.
>
> _**Validación No Conforme (Rechazado):**_ El producto requiere correcciones. Se le entregará una Geodatabase de Inconsistencias (GDB) que muestra dónde están los errores para que usted pueda corregirlos y volver a subir el producto.
