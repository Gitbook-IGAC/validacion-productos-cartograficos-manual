# Información general

<figure><img src="../.gitbook/assets/int_03.png" alt=""><figcaption></figcaption></figure>

En esta sección se despliega la información general asociada a cada producto. Aquí inicia el proceso de edición y registro de los resultados de validación. A continuación, se muestra la interfaz general del módulo inicial, la cual mantiene la misma estructura para los tres tipos de producto, con excepción de algunas casillas específicas según el tipo de insumo (MDT, base de datos vectorial u ortoimagen).

Para comenzar la validación, se debe hacer clic sobre el registro del radicado, lo que permitirá acceder a todos los indicadores disponibles para el proceso de validación.
