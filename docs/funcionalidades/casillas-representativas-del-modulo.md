# Casillas representativas del módulo

<figure><img src="../.gitbook/assets/int_04.png" alt=""><figcaption></figcaption></figure>

Cuando un producto ha sido asignado al profesional de validación, gran parte de los campos del formulario ya vienen diligenciados desde la etapa de radicación. Algunos de estos campos permanecerán inhabilitados según el tipo de producto a evaluar. A continuación, se describen las casillas más relevantes y aquellas que deben ser completadas durante la edición de la validación:

* **Fecha estimada de entrega:** Este campo lo define el supervisor al momento de asignar el radicado, considerando la escala y el área del producto a validar.
* **Área de cubrimiento del proyecto:** Su contenido depende directamente de la escala del producto. A continuación, se despliegan las opciones:

1. **Rural – Municipal** (aplican generalmente para escalas 1:5.000, 1.10.000, 1:25.000)
2. **Urbano – Cabecera municipal** (Aplica para escalas 1:1.000 y 1:2.000)
3. **Urbano – Centro poblado** (Aplica para escalas 1:1.000 y 1:2.000)

* **Tipo de producto:** Permite seleccionar entre los tres tipos habilitados en la plataforma (MDT, base de datos vectorial u ortoimagen).

![](<../.gitbook/assets/Unknown image (112)>)

<p align="center"><sup><em>Tipo de productos a validar</em></sup></p>

* **Fecha de captura:** Corresponde a la fecha en que fue capturado el insumo; esta fecha debe ser coherente entre los tres tipos de productos asociados al proyecto.
* **Tipo de captura:** Esta casilla la encontraras habilitada únicamente para productos de bases de datos vectoriales. Indica si el producto fue obtenido por restitución o digitalización 2D. Para los demás productos permanecerá inhabilitada, resaltado en una tonalidad gris.

![](<../.gitbook/assets/Unknown image (113)>)

<p align="center"><sup><em>Tipos de captura – Base de datos vectorial</em></sup></p>

* **Área de proyecto:** Área en hectáreas definida por el límite del proyecto.
* **Bloque:** Aplica para proyectos de gran escala que fueron divididos en partes.
* **Sensor:** Disponible para ortoimágenes y modelos digitales de terreno, permite indicar el sensor utilizado para la adquisición.
* **Escala:** Despliega un listado de las diferentes escalas de trabajo y determina los parámetros y criterios de validación aplicables.

* **Área validada:** Este campo es diligenciado por el profesional, indicando el porcentaje del área verificada. Para escalas 1:1.000 y 1:2.000 normalmente se valida el 100%, excepto cuando el área supera 60 hectáreas. Para áreas mayores a 100 hectáreas, la validación se realiza por muestreo y en esta casilla se registra el porcentaje validado.
* **Total de marcos:** Esta casilla es aplicable en validaciones por muestreo. Durante el proceso de validación se calcula automáticamente mediante una herramienta el número de marcos necesarios según el área y la escala, y en esta casilla se consigna el número de marcos utilizados durante la verificación.
* **Inspección No:** Indica el número de inspección correspondiente. La plataforma contempla tres inspecciones iniciales y una inspección final.

![](<../.gitbook/assets/Unknown image (117)>)

<p align="center"><sup><em>Números de inspección</em></sup></p>

* **Archivo de entrega:** El productor consigna aquí la ruta donde dispone el producto y sus soportes. A partir de esta información, el profesional realiza la revisión detallada y la posterior validación del producto.
