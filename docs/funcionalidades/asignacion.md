Este tutorial explica de manera clara y guiada las principales funcionalidades de la herramienta de validación de Colombia en Mapas. A través de él podrás comprender cómo se realiza el cargue de la información de validación, cuáles son los parámetros y criterios más relevantes para cada tipo de producto, y cómo se interpretan los indicadores de evaluación, la interfaz y los resultados generados por el sistema para cada proceso de validación.

### Asignación de validación

Una vez los productos (tanto de origen interno como externo) han sido oficializados dentro de la plataforma, el supervisor responsable del proceso genera una solicitud de asignación dirigida al profesional encargado de la validación. De forma automática, el sistema envía un correo electrónico notificando el número del radicado asignado, como se muestra a continuación:

![](<../.gitbook/assets/Unknown image (107)>)

<p align="center"><sup><em>Estructura de correo de asignación</em></sup></p>

En este correo, el asunto indica el número de radicado y el tipo de producto a validar. El cuerpo del mensaje incluye un resumen del detalle del proceso, especificando información como: tipo de producto, área asociada, entidad productora y demás datos relevantes.

Con el número de radicado asignado, el validador debe ingresar a la plataforma Colombia en Mapas. En la pestaña **“Radicado”**, se digita el número recibido y el sistema desplegará automáticamente el registro correspondiente para iniciar el proceso de validación.
